## 2026-07-18 - XSS in Post Content Rendering\n**Vulnerability:** XSS via `dangerouslySetInnerHTML` rendering unsanitized `post.content` in `src/app/blogs/[id]/page.tsx`.\n**Learning:** React's `dangerouslySetInnerHTML` is literally dangerous. Rendering user-generated content without sanitization can lead to XSS. Even if the data comes from an API, it cannot be trusted if it originates from user input.\n**Prevention:** Always sanitize HTML content before rendering it using `dangerouslySetInnerHTML`. Use a robust library like `isomorphic-dompurify` in Next.js to handle SSR/CSR properly.
