## 2023-10-23 - Fix XSS Vulnerability in Blog Detail Page\n**Vulnerability:** Cross-Site Scripting (XSS) via unsanitized `post.content` rendered with `dangerouslySetInnerHTML` in `src/app/blogs/[id]/page.tsx`.\n**Learning:** The blog application used `dangerouslySetInnerHTML` to render HTML content from backend API directly without proper sanitization, allowing potential script injection. In Next.js (SSR), we need `isomorphic-dompurify` rather than standard `dompurify`.\n**Prevention:** Always use `isomorphic-dompurify` to wrap user-generated HTML content before feeding it to `dangerouslySetInnerHTML`.
