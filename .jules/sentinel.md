## 2026-09-21 - XSS Vulnerability in dangerouslySetInnerHTML\n**Vulnerability:** Raw HTML from user input (post.content) was rendered directly using dangerouslySetInnerHTML without sanitization.\n**Learning:** This is a classic Cross-Site Scripting (XSS) vulnerability that allows attackers to execute arbitrary JavaScript in the context of the user's browser.\n**Prevention:** Always sanitize user-provided HTML content before rendering it using a library like DOMPurify.
