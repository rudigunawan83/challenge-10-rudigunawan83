## 2025-02-27 - Cross-Site Scripting (XSS) in Blog Content Rendering
**Vulnerability:** Found a Cross-Site Scripting (XSS) vulnerability in `src/app/blogs/[id]/page.tsx` where user-generated blog content (`post.content`) was rendered directly into the DOM using React's `dangerouslySetInnerHTML` without any prior sanitization. This allowed attackers to inject malicious HTML or `<script>` tags that would execute in other users' browsers when viewing the post.
**Learning:** `dangerouslySetInnerHTML` bypasses React's built-in XSS protection (which automatically escapes strings). It should never be used with user-generated content unless that content has been strictly sanitized on the client or server side first.
**Prevention:** Always use a trusted sanitization library (like `isomorphic-dompurify` for SSR-compatible Next.js apps) to clean HTML content before passing it to `dangerouslySetInnerHTML`: `<article dangerouslySetInnerHTML={{ __html: DOMPurify.sanitize(post.content) }} />`.
