## 2024-05-24 - Avoiding N+1 queries in list-rendered modals
**Learning:** When modals containing data-fetching hooks (like `useQuery`) are rendered inside a list (e.g., `BlogCard` mapping over posts), they can cause a massive N+1 API request problem on page load if the modal is mounted but hidden (e.g., using early returns instead of conditional rendering for the whole component, or conditionally rendering without considering that the hook runs before the return). Even if conditionally rendered, it's safer to ensure internal queries require the modal's open state.
**Action:** Always ensure that data-fetching queries inside hidden or modal components explicitly depend on the component's visibility state, e.g., by adding `open` to the `enabled` option of React Query hooks: `enabled: open && ...`. Do not rely solely on conditional rendering in the parent if exit animations are required or if the modal component itself is unconditionally mounted.
