## 2026-10-10 - Prevent N+1 query in hidden modal\n**Learning:** When modals containing React Query hooks are placed inside a list (like a feed of posts), rendering the modal components will trigger API queries immediately unless explicitly disabled, leading to N+1 API requests on page load. You cannot conditionally render the modal wrapper with `{isOpen && <Modal />}` if the modal relies on the `open` prop for exit animations.\n**Action:** Add the modal's visibility state (`open`) to the `enabled` condition of internal `useQuery` hooks (`enabled: open && ...`) to prevent unnecessary network requests while keeping exit animations intact.
