## 2024-05-24 - Prevent N+1 API Calls from Hidden Modals in Lists
**Learning:** Rendering hidden modals (like `StatisticModal`) inside list items (like `BlogCard`) causes internal `useQuery` hooks to execute immediately on mount if they lack an `open` condition in their `enabled` setting. This creates a massive N+1 API request pattern whenever a page displaying multiple list items is loaded. You cannot conditionally render the modal wrapper in the parent (`{isOpen && <Modal />}`) because it breaks UI exit animations relying on the `open` prop.
**Action:** When creating or optimizing modals intended to be placed inside lists, ensure any internal data-fetching (like `useQuery`) explicitly checks that the modal is currently open (`enabled: open && ...`) rather than unconditionally fetching.
