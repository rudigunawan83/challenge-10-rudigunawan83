## 2024-03-01 - Prevent N+1 API Calls on Hidden Modals
**Learning:** When optimizing hidden modals in lists, conditionally rendering the modal wrapper (e.g., `{isOpen && <Modal open={isOpen} />}`) can break UI exit animations that rely on the `open` prop.
**Action:** Instead, solely prevent massive N+1 API requests on page load by verifying that any internal data-fetching (like `useQuery`) explicitly requires the modal to be open (`enabled: isOpen && ...`).
