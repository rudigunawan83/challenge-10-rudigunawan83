## 2026-08-24 - Prevent N+1 queries in hidden modals\n**Learning:** In React components that accept an `open` state for visibility (like modals rendered in lists), `useQuery` hooks that fetch data should use the `enabled: open` property to prevent fetching data for *all* items on page load, which causes an N+1 API request flood.\n**Action:** When implementing or optimizing modals containing network requests, verify that data fetching is deferred until the modal is actively opened.
