## 2025-02-18 - [Next.js App Router Static Generation CSR Bailout & Modal N+1 Queries]
**Learning:** In Next.js App Router, failing to wrap components that utilize the `useSearchParams()` hook with a `<Suspense>` boundary will trigger a CSR bailout, failing static generation (`npm run build`). Additionally, rendering hidden modals (like `StatisticModal.tsx`) inside iterated lists (like `BlogCard.tsx`) without gating their internal `useQuery` hooks based on an `open` prop triggers massive N+1 API request cascades during page load.
**Action:** Always wrap client components utilizing `useSearchParams()` inside a `<Suspense>` boundary when migrating/building Next.js apps. To prevent N+1 API request issues with hidden modals in lists, rather than conditionally unmounting the modal (which may break exit animations), ensure internal queries are disabled unless the modal is open (e.g., `enabled: open && ...`).
