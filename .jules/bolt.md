## 2024-06-25 - Prevent N+1 API Requests from Hidden Modals in Lists
**Learning:** In Next.js/React applications, when mapping over a list of items (like blog posts) and rendering a hidden modal for each item (like a statistics modal) that contains internal data-fetching logic (e.g., `useQuery`), the queries will run immediately for all items on page load, causing massive N+1 API requests, even if the modal is closed. Modifying the modal wrapper to conditionally render (`{isOpen && <Modal/>}`) breaks exit animations.
**Action:** Always inspect hidden components within lists for data fetching. Use React Query's `enabled` option tied to the `open` prop (`enabled: open && ...`) to defer API calls until the user explicitly opens the modal, preserving both performance and animations.
